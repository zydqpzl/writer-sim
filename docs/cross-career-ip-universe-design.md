# 跨职业 IP 循环生态设计储备文档

> 状态：设计储备（待 UP 主、独立开发等职业落地后接入）
> 关联文档：`GAME_SYSTEMS.md`、`CONTENT_EXPANSION.md`

## 1. 设计目标

让《毕业咸鱼模拟器》中的不同自由职业不是孤立的小游戏，而是共用同一个**社会热点池（Global Trends）**与**跨职业 IP 库（Shared Universe IP）**。玩家在任何一条职业线上产出的爆款内容，都会成为其他职业线的素材、机遇或风险来源，形成“一个梗养活一圈人”的真实网络生态。

## 2. 核心循环

```text
[网文爆火] ──(改编/解说)──> [UP主做视频吐槽/安利] ──(二创破圈)──> [独立开发者做同人游戏]
     ^                                                                     |
     └──────────────────────(梗出圈，反哺新书选题)──────────────────────────┘
```

## 3. 全局数据结构（建议）

在 `GameState` 中预留跨职业共享数据：

```typescript
export interface SharedUniverseIP {
  id: string
  sourceCareer: 'WRITER' | 'STREAMER' | 'INDIE_DEV'
  title: string
  genre: string
  hype: number        // 知名度/热度
  reputation: number  // 口碑
  originDay: number
}

// 在 GameState 中新增字段
sharedUniverseIPs: SharedUniverseIP[]
```

## 4. 跨职业联动细则

### 4.1 网文 → 视频（UP 主职业）

当玩家或市场中热度 ≥ 80 的小说自动进入 UP 主选题库，分为两类：

| 视频类型 | 触发效果 | 对原作影响 |
| :--- | :--- | :--- |
| 吐槽/烂尾盘点 | UP 主获得高播放量，但评论区骂战 | 原作读者情绪 -15，爆点 +10 |
| 高燃剪辑/安利 | UP 主获得稳定正向流量 | 原作新增“自来水读者”，追读 +5% |
| 深度解说世界观 | 适合复杂/考据向作品 | 原作口碑 +10，吸引老白读者 |

未来 UP 主职业可直接接“网文推广单”或“锐评当红网文”。

### 4.2 视频 → 网文（作家职业）

视频区的热梗与大事件会转化为作家的**限时热点噱头**，开书时若选择匹配噱头：

- 限时 7 天内提供 +20% 开书爆点加成。
- 过期后加成消失，但已开作品保留基础效果。

示例热点转化：

| 视频热点 | 转化噱头 | 加成 |
| :--- | :--- | :--- |
| 某游戏大暴死 | “让你做游戏，你做出了电子酷刑？” | 爆点 +25% |
| 主播翻车 | “全网最真情实感的人设崩塌现场” | 爆点 +20%，风险 +10% |
| 科技狠活 | “我在修仙界搞食品工程打假” | 商业性 +15% |

### 4.3 网文 / 视频 → 独立游戏（独立开发职业）

独立开发者可消耗少量“改编版权金”购买已爆火内容的**同人游戏改编权**：

- 优势：自带 IP 热度，初期宣发成本大幅下降。
- 风险：原作口碑崩塌会连带影响游戏评价；若改编过度魔改，原作粉差评。
- 特殊事件：当某小说 hype ≥ 90 时，开发者可能收到原作粉丝众筹“求你做游戏”。

## 5. 同人衍生事件链调度（已落地）

网络作家职业内已落地的同人专属事件链：

- `fanfiction_blowup`：同人大爆，原作作者盯上你
- `fanfiction_copyright`：同人收到版权警告
- `fanfiction_payback`：原作粉丝自来水反哺

触发条件详见 `src/hooks/useGame.ts` 中 `checkWriterEventTriggers`。

## 7. 数值设计原则

- **热度会衰减**：跨职业反哺不应无限叠加，设置 7~14 天衰减周期。
- **口碑会传染**：原作/视频/游戏任一环节崩塌，关联内容都承受 10%~30% 口碑冲击。
- **稀缺性**：不是每个爆款都能改编游戏，只有 hype ≥ 80 且口碑 ≥ 60 的作品才进入改编候选池。
