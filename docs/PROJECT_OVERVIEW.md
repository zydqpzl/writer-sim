# 毕业咸鱼模拟器 —— 项目总览

> 本文档面向非程序背景的协作者（策划、文案、Aymo AI）。
> 如果你需要了解具体代码实现，请查看 `docs/GAME_SYSTEMS.md` 和 `docs/AYMO_AI_GUIDE.md`。

---

## 1. 一句话介绍

《毕业咸鱼模拟器》是一个以**当代年轻人自由职业生存**为主题的叙事向模拟游戏。

玩家扮演一名刚毕业、不想上班的年轻人，在 60 天（试用期长度）内尝试通过网文作家、UP 主、独立开发等自由职业养活自己，同时面对房租、健康、父母压力、社会偏见等现实问题。

---

## 2. 核心立意

- **打破偏见**：自由职业不是"不务正业"，但也绝非"躺着赚钱"。
- **真实困境**：展示自由职业者的高压、焦虑、收入不稳定。
- **成长与选择**：玩家的每个选择都会塑造角色的人生路径和最终结局。

---

## 3. 游戏主循环

```text
每天 3 个时段（上午 / 下午 / 晚上）
    ↓
玩家选择一项行动
    ↓
消耗精力、压力、金钱，可能获得收益/粉丝/经验
    ↓
触发随机事件、事件链、社会/家庭遭遇
    ↓
进入下一时段或下一天
    ↓
每日结算：扣除生活费、结算收益、更新状态
```

## 5. 关键资源与胜负条件

### 5.1 玩家核心属性

| 属性 | 含义 | 危险线 |
|------|------|--------|
| 存款 | 手里可用的钱 | < 0 时破产 |
| 健康 | 身体状况 | 过低会住院 |
| 精力 | 每天可行动的体力 | 耗尽后无法工作 |
| 压力 | 精神负担 | 过高会触发崩溃事件 |
| 父母满意度 | 父母对你的认可 | < 0 会被抓回家考编 |
| 粉丝数 | 职业影响力 | 影响结局判定 |

### 5.2 败北条件

- 存款 < 0：破产
- 健康 < 0：住院
- 父母满意度 < 0：被抓回家

### 5.3 胜利条件

撑过 60 天，并且职业影响力（粉丝/作品收益）达到"可以自食其力"的阈值，解锁"独立自由人"结局。

## 6. 项目技术栈

- **前端框架**：React
- **样式**：Tailwind CSS
- **构建工具**：Vite
- **语言**：TypeScript
- **输出形式**：单页 Web 应用（可部署到任意静态托管）

> 作为协作者，你不需要写代码，但需要知道：所有游戏数据（数值、文案、事件）都以配置文件的形式存在，修改这些文件就能改变游戏内容。

---

## 7. 重要文件夹说明

```text
docs/                  ← 你正在看的文档
src/
  components/          ← UI 组件（显示面板、弹窗等）
  data/                ← 游戏数据配置文件（策划重点）
  engine/              ← 核心算法（结算、计算）
  hooks/               ← 游戏状态管理
  types/               ← 数据类型定义
PRD.md                 ← 产品需求文档（原始）
```

对策划和文案来说，最重要的是 `src/data/` 文件夹。

## 9. 后续开发方向（按优先级）

1. **完善网络作家职业**：增加更多事件链、背景标签、文风特质、读者评论。
2. **扩展 UP 主 / 主播职业**：引入视频创作、平台算法、直播打赏等机制。
3. **扩展独立开发者职业**：引入项目开发、Bug、发布、融资等机制。
4. **多周目与遗产系统**：继承上一局的特质/卡牌，形成长期成长感。
5. **更多结局**：根据玩家的职业路径、财富、健康、家庭关系给出不同结局。
