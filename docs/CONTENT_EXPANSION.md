# 毕业咸鱼模拟器 —— 内容扩展指南

> 本文档说明如何在不改动核心代码的情况下，为游戏添加新内容。
> 适合策划、文案、以及通过 Aymo AI 协作扩展内容时使用。

---

## 1. 扩展内容的基本原则

1. **数据驱动**：大部分内容通过修改 `src/data/` 下的配置文件实现。
2. **保持一致性**：新内容需符合现有类型定义和数值范围（0-100、0-1 等）。
3. **主题契合**：内容应围绕"自由职业生存""当代年轻人焦虑""现实与梦想冲突"展开。
4. **先小后大**：建议先添加单个事件/背景/标签，验证效果后再批量扩展。

## 3. 添加新履历背景标签

### 3.1 文件位置

`src/data/backgrounds.ts`

### 3.2 背景标签结构

每个背景标签包含：

| 字段 | 说明 |
|------|------|
| `id` | 唯一标识符，英文，如 `medical_student` |
| `name` | 显示名称，如 "医学生/医生" |
| `category` | 分类：`EDUCATION` / `PROFESSION` / `FAMILY` / `PAST_WRITING` |
| `description` | 描述文案 |
| `skillModifiers` | 对作者五维技能的修正 |
| `genreSynergies` | 与特定题材的化学反应 |
| `globalEffects` | 全局效果（可选）：初始粉丝、追读修正、隐患值等 |

### 3.3 化学反应结构

每个化学反应包含：

| 字段 | 说明 |
|------|------|
| `targetGenre` | 目标题材 ID |
| `synergyName` | 化学反应名称，如 "硬核解剖" |
| `qualityBonus` | 质量加成倍率，如 0.25 表示 +25% |
| `commercialityBonus` | 商业加成倍率（可选） |
| `retentionBonus` | 追读加成倍率（可选） |
| `requiredDomain` | 需要的专精知识门槛（可选） |
| `uniqueReaderComments` | 专属读者评论池，随机显示 |

### 3.4 示例

```typescript
const exampleTag: BackgroundTag = {
  id: 'lawyer',
  name: '前实习律师',
  category: 'PROFESSION',
  description: '熟悉法律条文与庭审流程，写律政/悬疑题材时逻辑严密。',
  skillModifiers: {
    prose: 5,
    structure: 10,
    domainKnowledge: { law: 70 },
  },
  genreSynergies: [
    {
      targetGenre: 'SUSPENSE',
      synergyName: '证据链大师',
      qualityBonus: 0.20,
      commercialityBonus: 0.10,
      uniqueReaderComments: [
        '这证据链梳理得太专业了，作者是不是真在检察院干过？',
        '别的悬疑靠猜，这本靠推理，舒服。',
      ],
    },
  ],
}
```

### 3.5 注意事项

- 加成数值建议控制在 0.05 ~ 0.30 之间，避免过度破坏平衡。
- 专属读者评论建议 2-4 条，体现"这个背景才写得出来"的真实感。
- 如果设置 `requiredDomain`，确保该领域知识可通过其他背景或游戏过程获得。

## 4. 添加新事件链

### 4.1 文件位置

- 事件链定义：`src/data/chains/*.ts`
- 注册事件链：`src/data/eventChains.ts`

### 4.2 事件链结构

事件链由多个步骤组成，每个步骤包含：

| 字段 | 说明 |
|------|------|
| `id` | 步骤唯一 ID |
| `title` | 弹窗标题 |
| `description` | 事件描述文案 |
| `options` | 玩家可选择的选项 |

每个选项包含：

| 字段 | 说明 |
|------|------|
| `text` | 选项文字 |
| `nextStepId` | 选择后进入的下一步 ID（可选，为空则结束） |
| `effects` | 对玩家属性的影响（可选） |
| `condition` | 出现条件（可选） |

### 4.3 设计建议

1. **有分支**：至少提供 2-3 个选项，让玩家有选择感。
2. **有代价**：好选项通常有代价，坏选项可能带来意外收获。
3. **符合主题**：事件应反映自由职业者的真实困境。
4. **有状态判定**：根据玩家当前状态（存款、健康、压力等）触发不同分支。

### 4.4 示例主题

- 房东催租事件链
- 同学聚会攀比事件链
- 网文被抄袭维权事件链
- 生病没钱去医院事件链
- 父母突然来访事件链

## 5. 添加新写作策略

### 5.1 文件位置

`src/data/writer.ts`

### 5.2 策略结构

每个写作策略包含：

| 字段 | 说明 |
|------|------|
| `id` | 唯一 ID |
| `name` | 显示名称 |
| `description` | 描述 |
| `strategy` | 策略类型：`SETUP` / `CLIMAX` / `FILLER` / `CLIFFHANGER` / `TROPE_INSERT` / `META` |
| `phaseRequired` | 可用阶段 |
| `cost` | 精力/压力/金钱消耗 |
| `effects` | 对作品三维的影响 |
| `wordCountAdd` | 增加字数 |
| `retentionDelta` | 追读率变化 |
| `readerMoodDelta` | 读者情绪变化 |
| `readerComments` | 本策略触发的读者评论池 |

### 5.3 设计建议

- 不同策略应形成明显差异：
  - `SETUP`：加质量、加结构力，但可能让读者觉得慢。
  - `CLIMAX`：加节奏感、加爆点，消耗大。
  - `FILLER`：快速堆字数，但掉口碑。
  - `CLIFFHANGER`：加追读，但读者情绪下降。
  - `TROPE_INSERT`：加爆点、加题材敏锐度。

## 9. 数值平衡参考

### 9.1 属性范围

| 属性 | 范围 | 说明 |
|------|------|------|
| 质量 / 商业性 / 爆点 | 0 - 100 | 作品三维 |
| 复杂度 / 掌控力 | 0 - 100 | 作品难度与作者能力 |
| 作者五维技能 | 0 - 100 | 单技能 |
| 追读率 | 0 - 1 | 百分比 |
| 读者情绪 | -100 - 100 | 正负面 |
| 隐患值 | 0 - 100 | 争议与风险 |

### 9.2 加成幅度建议

| 效果类型 | 建议范围 | 说明 |
|----------|----------|------|
| 质量加成 | 5% - 30% | 履历化学反应 |
| 商业加成 | 5% - 20% | 避免收益爆炸 |
| 追读加成 | 2% - 10% | 小幅但持续有效 |
| 技能修正 | -20 - +40 | 大幅修正应有代价 |
| 事件属性影响 | ±5 - ±30 | 根据事件重要性 |

## 10. 扩展流程 checklist

当你想添加新内容时，建议按以下步骤：

1. **明确目标**：这个内容想表达什么？给玩家带来什么选择？
2. **查找相似内容**：参考现有文件中同类内容的写法。
3. **复制模板**：基于现有条目创建新条目。
4. **填写字段**：确保所有必填字段都有值。
5. **检查一致性**：ID 是否唯一？数值是否在合理范围？题材 ID 是否正确？
6. **本地验证**：让 TraeDesign 或开发者运行 `npm run build` 检查是否有报错。
7. **游戏体验测试**：在浏览器中实际触发，观察效果是否符合预期。

## 11. 与 Aymo AI 协作扩展内容

如果你通过 Aymo AI 扩展内容，建议：

1. 先让 Aymo AI 阅读 `docs/GAME_SYSTEMS.md` 和本文档。
2. 明确告诉 Aymo AI 你想扩展的类型（如"添加 3 个新履历背景"）。
3. 提供主题方向和参考例子。
4. 让 Aymo AI 生成内容后，交给 TraeDesign 或开发者写入对应文件并验证。
5. 不要直接让 Aymo AI 修改代码文件，除非它明确懂得如何保持类型一致。
